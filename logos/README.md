# Logos

Drop the official logos here. The footer (`src/components/footer.js`) expects these file names
(SVG preferred, PNG at least 144×144 px is fine):

| File         | Logo                                           |
| ------------ | ---------------------------------------------- |
| `bsc-ku.svg` | Biological Sciences Club, Kuwait University    |
| `ku.svg`     | Kuwait University                              |
| `cs.svg`     | Computer Science students / department (optional) |

Missing files are hidden automatically, so the site works before logos are added.
If you use `.png`, update the `LOGOS` list in `src/components/footer.js`.
